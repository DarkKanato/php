# Task & Habit Tracker

Трекер задач и привычек: регистрация, список дел, ежедневные отметки привычек
и простая аналитика (стрики, процент выполнения, активность за неделю).

Это мой учебный пет-проект, на котором я учил PHP и Yii2. Репозиторий специально
оставлен с полной историей: в ней видно, как код эволюционировал от одного
php-файла до приложения на фреймворке.

**Стек:** PHP 8.2+, Yii2 (Basic Template), SQLite, Bootstrap 5.

## Возможности

- регистрация / вход / выход, пароли хранятся только в виде хеша;
- задачи: приоритет, срок выполнения, статус, фильтры «все / открытые / выполненные»;
- привычки: отметка «выполнено сегодня» (повторное нажатие отменяет отметку);
- дашборд: открытые и просроченные задачи, привычки за сегодня, лучший стрик,
  выполнение за 30 дней и «полоска» последних 7 дней по каждой привычке;
- flash-сообщения, валидация форм на сервере, CSRF-защита.

## Как запустить

Нужны PHP 8.2+ с расширением `pdo_sqlite` и [Composer](https://getcomposer.org/).

```bash
git clone <repo-url> habit-tracker
cd habit-tracker

composer install          # зависимости
php yii migrate           # создаст runtime/tracker.sqlite и таблицы
php yii seed              # (необязательно) демо-данные: demo / demo1234
php yii serve             # http://localhost:8080
```

Если в окружении нет доступа к `asset-packagist.org`, `composer install` не
сможет скачать bower-пакеты, от которых зависит ядро Yii2 (jQuery и др.).

Ничего настраивать не нужно: база - файл `runtime/tracker.sqlite`, секретный ключ
для cookie генерируется при первом запросе и лежит в `runtime/cookie.key`
(папка `runtime/` не коммитится).

## Структура

```
commands/        консольные команды (php yii seed)
config/          конфиги приложения (web, console, db)
controllers/     тонкие контроллеры: Site, Task, Habit
migrations/      миграции: user, task, habit_log
models/          ActiveRecord: User, Task, HabitLog + форма LoginForm
services/        StatsService - вся аналитика для дашборда
views/           шаблоны (Bootstrap 5)
legacy/          старый самописный MVC (для истории, не используется)
```

## Архитектурные решения

- **Тонкие контроллеры.** Контроллер только принимает запрос, вызывает модель/сервис
  и выбирает, что отрисовать. Подсчёт стриков и процентов вынесен в `StatsService`.
- **Одна таблица для задач и привычек.** Различаются полем `type`; сценарии валидации
  модели `Task` (`task` / `habit`) определяют, какие поля вообще можно заполнить.
  Отметки привычек лежат в `habit_log` с уникальным индексом `(task_id, log_date)`,
  так что дважды отметить один день нельзя даже при гонке запросов.
- **Доступ только к своим данным.** Все выборки по id идут через `Task::findOwned()`;
  чужая запись даёт 404, а не 403, чтобы нельзя было перебирать id. Изменяющие
  действия (удаление, отметка) разрешены только через POST (`VerbFilter`).
- **Безопасность.** Пароли - `Yii::$app->security->generatePasswordHash()`, CSRF-токены
  в каждой форме, одинаковое сообщение об ошибке для «нет такого пользователя» и
  «неверный пароль».
- **SQLite и внешние ключи.** SQLite по умолчанию их не проверяет, поэтому на каждое
  соединение выполняется `PRAGMA foreign_keys = ON` (`config/db.php`), а связи
  объявлены прямо в `CREATE TABLE` внутри миграций (`ALTER TABLE ADD FOREIGN KEY`
  в SQLite не поддерживается).
- **Стрик не сгорает до конца дня.** Если сегодня привычку ещё не отметили, серия
  считается от вчерашнего дня.

## Путь разработки

| Этап | Что делал | Чему научился |
|------|-----------|---------------|
| Апрель 2024, процедурный PHP | Регистрация, вход, список задач на PDO + SQLite | Сессии, PDO, формы |
| | Нашёл у себя SQL-инъекцию и `md5` для паролей - переписал на prepared statements и `password_hash` | Основы безопасности, `htmlspecialchars` |
| | Привычки, отметки по дням, страница со статистикой | Работа с датами, SQL-агрегаты |
| Конец апреля, свой MVC | Singleton для подключения, затем Router / Controller / Model | Паттерн MVC, автозагрузка классов |
| Май 2024, Yii2 | Переезд на Yii2 Basic: миграции, ActiveRecord, валидация, сценарии, связи | Жизненный цикл Yii, `AccessControl`, `VerbFilter`, ActiveForm, поведения |
| | Закрыл дыру в доступе к чужим задачам, добавил аналитику и дашборд | Сервисный слой, борьба с N+1 |
| Июнь 2024 | README, сидер демо-данных | |

Старый самописный MVC лежит в `legacy/mvc-prototype` (запуск:
`php -S localhost:8000 -t legacy/mvc-prototype/public`).
